## 🎯 วัตถุประสงค์ของโครงงาน
เพื่อพัฒนาเกมแนว **2D Action Adventure** ที่ผู้เล่นสามารถควบคุมตัวละครหลักต่อสู้กับศัตรูในแต่ละฉาก เดินเปลี่ยนฉากได้ และมีระบบความเสียหาย การตาย และ Game Over ครบถ้วน  
โครงงานนี้มีจุดประสงค์เพื่อฝึกทักษะการพัฒนาเกม การเขียนโปรแกรมเชิงวัตถุและการออกแบบระบบเกมอย่างเป็นขั้นตอน

---

## 🏞️ รายละเอียดของเกม

### 🧩 จำนวนฉากทั้งหมด
1. **Scene 0 – Start Scene (หน้าเริ่มเกม)**  
   - แสดงชื่อเกม  
   - ปุ่ม “Start” และ “Exit”  
   - กด “Start” เพื่อเข้าสู่เกม  

2. **Scene 1 – Forest Zone (ป่าเริ่มต้น)**  
   - ฉากเริ่มต้นสำหรับฝึกควบคุม  
   - มีศัตรูเดินภายในฉาก  
   - มีจุดทางออกไปฉากถัดไป  

3. **Scene 2 – Abandoned Village (หมู่บ้านร้าง)**  
   - ศัตรูเริ่มโจมตี
   - มีสิ่งกีดขวาง เช่น หลุม หรือกับดัก  

4. **Scene 3 – Mystic Cave (ถ้ำลึกลับ)**  
   - ศัตรูโจมตี 
   - ต้องหาทางออกให้เจอเพื่อผ่านฉาก  

5. **Scene 4 – Dark Castle (ปราสาทมืด)**  
   - ศัตรูโจมตี  
   - มีสิ่งกีดขวาง เช่น หลุม หรือกับดัก 
   - การกระโดดในด่านยาก 

6. **Scene 5 – Game Over / Ending Scene (ฉากจบ)**  
   - แสดงข้อความ “Game Over” หรือ “You Win!”  
   - มีปุ่ม “Restart” หรือ “Exit”

## ⚔️ ระบบหลักของเกม

### 🧍‍♂️ ระบบผู้เล่น (Player System)
- ผู้เล่นสามารถ **เดิน ซ้าย/ขวา** และ **โจมตี** ได้  
- สามารถ **เปลี่ยนฉาก** ได้เมื่อเดินถึงจุดทางออก  
- เมื่อโดนโจมตีจากศัตรูจะ **ลดพลังชีวิต**  
- ถ้าพลังชีวิตหมดจะเข้าสู่ฉาก **Game Over**

### 👾 ระบบศัตรู (Enemy System)
- ศัตรูสามารถเดินไปมาภายในฉาก  
- ตรวจจับผู้เล่นเมื่อเข้าใกล้  
- ถูกโจมตีได้และจะตายเมื่อพลังชีวิตหมด  

### ⚔️ ระบบต่อสู้ (Combat System)
- มีการคำนวณความเสียหาย (Damage) ทั้งผู้เล่นและศัตรู  
- แสดงเอฟเฟกต์การโจมตี  
- เมื่อศัตรูถูกกำจัดจะเล่นอนิเมชันตายและหายไป  

### 🎞️ ระบบอนิเมชัน (Animation System)
- ตัวละครผู้เล่นมีอนิเมชันเดิน, โจมตี, ถูกโจมตี, และตาย  
- ศัตรูมีอนิเมชันเดิน, โจมตี, และตาย  

### 🔊 ระบบเสียง (Sound System)
- เสียงพื้นหลังในแต่ละฉาก  
- เสียงโจมตี, เสียงศัตรูตาย, และเสียง Game Over
