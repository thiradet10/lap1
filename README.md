## 🎯 วัตถุประสงค์ของโครงงาน
เพื่อพัฒนาเกมแนว **2D Action Adventure** ที่ผู้เล่นสามารถควบคุมตัวละครหลักต่อสู้กับศัตรูในแต่ละฉาก เดินเปลี่ยนฉากได้ และมีระบบความเสียหาย การตาย และ Game Over ครบถ้วน  
โครงงานนี้มีจุดประสงค์เพื่อฝึกทักษะการพัฒนาเกม การเขียนโปรแกรมเชิงวัตถุ (OOP) และการออกแบบระบบเกมอย่างเป็นขั้นตอน

---

## 🏞️ รายละเอียดของเกม

### 🧩 จำนวนฉากทั้งหมด
1. **Scene 0 – Start Scene (หน้าเริ่มเกม)**  
   - แสดงชื่อเกม  
   - ปุ่ม “Start” และ “Exit”  
   - กด “Start” เพื่อเข้าสู่เกม  

2. **Scene 1 – Forest Zone (ป่าเริ่มต้น)**  
   - ฉากเริ่มต้นสำหรับฝึกควบคุม  
   - มีศัตรูเดินภายในฉาก  
   - มีจุดทางออกไปฉากถัดไป  

3. **Scene 2 – Abandoned Village (หมู่บ้านร้าง)**  
   - ศัตรูเริ่มโจมตีแรงขึ้น  
   - มีสิ่งกีดขวาง เช่น หลุม หรือกับดัก  

4. **Scene 3 – Mystic Cave (ถ้ำลึกลับ)**  
   - ศัตรูโจมตีระยะไกล  
   - ต้องหาทางออกให้เจอเพื่อผ่านฉาก  

5. **Scene 4 – Dark Castle (ปราสาทมืด)**  
   - บอสใหญ่รออยู่  
   - เมื่อกำจัดบอสได้จะผ่านเกม  

6. **Scene 5 – Game Over / Ending Scene (ฉากจบ)**  
   - แสดงข้อความ “Game Over” หรือ “You Win!”  
   - มีปุ่ม “Restart” หรือ “Exit”

## ⚔️ ระบบภายในเกม

- **ระบบควบคุมผู้เล่น (Player Control System)**  
  - เดินซ้าย / ขวา  
  - โจมตีศัตรู  
  - เปลี่ยนฉากได้เมื่อถึงจุดทางออก  

- **ระบบศัตรู (Enemy System)**  
  - เดินภายในฉาก  
  - ตรวจจับผู้เล่น  
  - เมื่อโดนโจมตีจะลดพลังชีวิตและตายได้  

- **ระบบต่อสู้ (Combat System)**  
  - ผู้เล่นสามารถโจมตีศัตรู  
  - ศัตรูสามารถสร้างความเสียหายให้ผู้เล่น  
  - เมื่อพลังชีวิตผู้เล่นหมด → Game Over  

- **ระบบอนิเมชัน (Animation System)**  
  - อนิเมชันการเดิน, โจมตี, โดนโจมตี และตาย  
  - ใช้กับทั้งผู้เล่นและศัตรู  

- **ระบบเสียง (Sound System)**  
  - เสียงพื้นหลังในแต่ละฉาก  
  - เสียงโจมตี / เสียงศัตรูตาย / เสียง Game Over

## ▶️ วิธีการเล่น

1. เปิดไฟล์ `SwordmanAdventure.exe` (หรือรันจาก Unity Editor)  
2. ที่หน้า **Start Scene** กด **Start Game**  
3. ใช้ปุ่มควบคุม  
   - ⬅️ ➡️ : เดินซ้าย/ขวา  
   - Spacebar : โจมตี  
   - W หรือ ↑ : กระโดด *(ถ้ามี)*  
4. เมื่อผู้เล่นเดินถึงทางออก → เปลี่ยนฉากใหม่  
5. ถ้าพลังชีวิตหมด → เข้าฉาก **Game Over**
